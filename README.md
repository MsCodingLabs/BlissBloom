# 🌸 BlissBlom – Entfalte dein inneres Glück

**Ein interaktives Erlebnis für Achtsamkeit, Selbstliebe und kleine Glücksmomente.**

BlissBlom schenkt dir mit jedem Klick eine sanfte Affirmation – versteckt hinter 26 stilisierten „Türen“. Die Anwendung lädt dazu ein, kurz innezuhalten, durchzuatmen und einen Moment für sich selbst zu genießen.

## Screenshot
![BlissBloom.png](https://github.com/MsCodingLabs/quizze/blob/main/quizze.png)

## ✨ Features

- 🌼 26 inspirierende Affirmationen hinter animierten Türen
- 🌈 Zufällige, bunte Effekte bei jeder Interaktion
- 💫 Weiches, beruhigendes Design – ideal für kleine Achtsamkeitspausen
- 🖱️ Intuitive Benutzeroberfläche – keine Anleitung nötig

## 💡 Idee

BlissBlom wurde als digitale Wellness-Meditation entworfen – ein stiller Begleiter für die Momente im Alltag, in denen du dir selbst ein Lächeln schenken möchtest. 

> "Dein Herz ist ein Garten – BlissBlom lässt ihn blühen."

## 🛠️ Technologien

- HTML
- CSS (mit Animationen & Farben)
- JavaScript (Zufallslogik & Interaktion)

## 📁 So funktioniert’s

1. Öffne `index.html` in deinem Browser.
2. Klicke auf eine der 26 Blüten-/Türen.
3. Lies die Affirmation – so oft du willst.
4. Erlebe kleine Überraschungseffekte bei jedem Klick.
